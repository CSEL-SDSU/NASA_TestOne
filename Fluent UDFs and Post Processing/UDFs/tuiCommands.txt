/Use these commands to autosave a .cgns file with the desired variables (once every specified amount of time). The first command is for the whole domain and the second is for a specified wall face. A third command is for turning off the ignitor zone after a specified time. This is for convenience, so you don't have to turn it off manually. /

Command 1:

(define fname1 (string-append "cellData_ts" (number->string (rpgetvar 'time-step)) ".cgns"))
(ti-menu-load-string
 (string-append
  "file/export/cgns
"
  fname1 "
"
  "
"                   
  "yes
"
  "yes
"
  "x-coordinate y-coordinate x-velocity y-velocity temperature pressure density molef-c6h10o5 molef-o2 molef-co2 molef-h2o molef-n2 net-rate-c6h10o5
"
  "()
"))


Command 2:

(define fname2 (string-append "faceData_ts" (number->string (rpgetvar 'time-step)) ".cgns"))
(ti-menu-load-string
 (string-append
  "file/export/cgns
"
  fname2 "
"
 "surface-select
"
 "rsurface                             //comment : replace rsurface with correct name of BC as needed
"
 "()
"                   
  "yes
"
  "yes
"
  "heat-flux udm-0 udm-1
"
  "()
"))

Command 3:
//comment : replace first number with correct zone id number as needed. I'd always double check these commands work between models

/define/boundary-conditions/fluid 45 fluid no no no no no 0 no 0 no no no yes yes 0
or
/define/boundary-conditions/fluid 17 fluid no no no no no yes yes no yes yes 0 

Command 4:
// Steady state to transient (test commands since some models change the order of responses) 
//these commands:change case to transient mode, activate and configure the above commands, disable this command block so it wont run twice, set the udfs at the sample boundary and function hook, turn on the ignitor, set the time step etc. and run the solver.

/define/models/unsteady-2nd-order yes                                                                                   
/solve/execute-commands/add-edit savefile no 1 "flow-time" ,
/solve/execute-commands/add-edit ignitoroff yes no "flow-time" 0.5 ,
/solve/execute-commands/disable sstot
/define/user-defined/function-hooks/execute-at-end "massSum::libudf" ""
/define/boundary-conditions/fluid 17 fluid no no yes no no no no no no no no no no no no yes 900 no no yes yes no yes yes 0
/define/boundary-conditions/wall sampleface no 0 no 0 no yes heat-flux yes yes udf "heat_absorption_rate::libudf" no no (no 1) yes yes yes yes yes yes udf "pyrolysis_release_rate::libudf" no 0 no 0 no 0 no 1 
/solve/set/time-step 0.001 
/solve/dual-time-iterate 15000 20          //comment: 15000/0.0001 = 15s at 20 iterations per timestep
